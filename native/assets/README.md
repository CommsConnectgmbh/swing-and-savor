# Capacitor Assets

This folder is consumed by `@capacitor/assets`. Place the following source files here:

- `icon.png` — 1024×1024 transparent or solid-bg icon (foreground)
- `icon-foreground.png` — 1024×1024 transparent foreground (Android adaptive)
- `icon-background.png` — 1024×1024 solid brand-dark background (#0d271e)
- `splash.png` — 2732×2732 portrait/landscape splash with logo centered on brand-dark

Then run `pnpm assets` (or `npm run assets`) to generate every iOS/Android variant.
